# Target-Conditioned Explainability (TCE)

A framework for evaluating how consistently a stance detection model explains its predictions when the target entity changes. Developed under the guidance of Mrs. Bhavani Samineni, Assistant Professor, Department of Computer Science and Engineering.

## What This Project Does

Stance detection models take a piece of text and a target entity as input, then predict whether the text expresses favor, opposition, or neutrality toward that target. The prediction accuracy of these models has been studied extensively, but a separate question has received little attention: when you substitute a semantically similar target (for example, replacing "climate change" with "environmental regulation"), does the model's internal reasoning stay the same, or does it shift entirely?

This matters because a model that gives the same prediction for two related targets but for completely different reasons cannot be reliably audited. Existing explanation tools like SHAP, LIME, and Partial Dependence Plots explain each prediction in isolation and provide no way to compare explanations across target variations.

TCE fills that gap. It takes the SHAP attribution vector produced under the original target and compares it against the attribution vectors produced under three semantically similar targets generated by Gemini, Qwen, and LLaMA. It then computes three metrics that together describe how much the explanation changed.

**Explanation Shift Score (ESS):** The average absolute difference in attribution magnitude across all tokens. A low ESS means each token's importance weight stayed roughly the same.

**Cosine Explanation Divergence (CED):** The cosine distance between the two attribution vectors. This captures directional divergence. A CED near zero means the explanation is pointing in the same direction; a CED near 2 means it is pointing in nearly the opposite direction.

**Token Flip Rate (TFR):** The fraction of the top five most influential tokens that are replaced when the target changes. A TFR of 0 means the same five tokens drove the prediction under both targets. A TFR of 1 means all five changed completely.

The framework was evaluated on 3,000 instances from the OpenTarget dataset (TSE and VAST sub-corpora), producing 9,000 pairwise comparisons across four fine-tuned Transformer models: DeBERTa, BERT-base-uncased, DistilBERT, and RoBERTa.

## Key Findings

DeBERTa produced the most consistent explanations across all three metrics. RoBERTa showed the most variability, with a CED nearly 2.5 times higher than DeBERTa on average.

Across all four models, predictions in the none (neutral) stance class were consistently the least stable. For RoBERTa, none-stance CED reached 1.14, approaching the theoretical maximum of 2. This finding is invisible to accuracy evaluation and cannot be surfaced by running SHAP or LIME on individual predictions.

Concrete, well-defined targets such as "wwii" and "legalization of abortion" produced near-zero TFR across models. Abstract policy topics such as "tax reform" and "net neutrality" produced token turnover as high as 87%, indicating that the model's reasoning for those targets shifts almost entirely when the target is rephrased.

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

The default configuration in `src/config.py` points to `data/cleaned_tweets.csv` and writes output to `outputs/metrics/xai_metrics_results.csv`. To run with DeBERTa (the default in main.py):

```bash
python main.py
```

To run with a different model, change the model name string passed to `load_model()` in `main.py` to any HuggingFace model identifier for a sequence classification model fine-tuned on three classes. The model must have been fine-tuned with the same input format used here: `[tweet] [SEP] Target: [target]`.

## Configuration Reference

All runtime parameters are set in `src/config.py`.

| Parameter | Default | Description |
|---|---|---|
| MAX_LEN | 128 | Token sequence length cap |
| MAX_EVALS | 50 | SHAP forward pass budget per explanation |
| N_BACKGROUND | 15 | Pool size for selecting the background reference |
| RANDOM_SEED | 42 | Seed for reproducibility |
| TOP_K | 5 | Number of top tokens used for TFR |
| N_SIMILAR | 3 | Number of similar targets per instance |

## Dataset Format

The input CSV at `data/cleaned_tweets.csv` must contain these columns:

| Column | Description |
|---|---|
| cleaned_tweet | Preprocessed tweet text |
| GT Target | The original ground-truth target entity |
| GT Stance | The stance label: AGAINST, NONE, or FAVOR |
| similar targets | A Python list or comma-separated string of three similar targets |

## Metrics Reference

| Metric | Range | Interpretation |
|---|---|---|
| ESS | 0 and above | Lower means attribution magnitudes are more stable |
| CED | 0 to 2 | 0 means identical direction; 2 means opposite direction |
| TFR | 0 to 1 | 0 means same top-5 tokens; 1 means completely different |

All three metrics should be considered together. ESS alone can underestimate instability: a model can show moderate ESS while having high CED, which means the attribution magnitudes are similar in size but pointing in different directions across targets.
